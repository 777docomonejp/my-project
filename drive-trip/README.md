# オヤジ3人旅特設アプリ（3人用 関東ドライブ旅行アプリ）

大阪府豊中市から車で埼玉県戸田市へ向かい、戸田で合流する3人のための旅行計画アプリです。
スマートフォン（iPhone Safari）向けの日本語Webアプリで、**APIキー・サーバー・有料サービス・アカウント登録なしで動きます。**

## 機能

| 画面 | できること |
| --- | --- |
| ホーム | 旅行の基本情報（出発・帰り・車・メモ）、メンバー3人の名前、宿泊先（アパホテル／ルートイン：名前・住所・宿泊日・予約状況・料金）の編集 |
| 観光地 | 関東7都県＋静岡・山梨の59か所（富士山の絶景、サウナ・居酒屋・ちゃんこを含む。戸田からの車の時間つき）の同梱データ、検索、県・ジャンル・状態での絞り込み、行きたい／保留／行かない、お気に入り、地図（OpenStreetMap＋Leaflet）、Googleマップの検索・ナビを開く、観光地の自分での追加、観光地ごとのコメント、投票、旅程への追加 |
| 旅程 | 日付・開始・終了・訪問先・移動時間・滞在時間、追加／編集／削除／並べ替え、時間の重複を警告、雨天時の代替 |
| 費用 | ガソリン（距離÷燃費×単価）・高速・駐車・宿泊・食事・入場料・その他、往路／復路／現地移動の別集計、概算と確認済みの区別、負担する人の指定、1人あたりの負担額 |
| 共有 | チャット、投票結果、暗号化した共有コードでの3人の同期、バックアップと復元、初期化 |

## 3人での共有のしくみ

サーバーを使わない「共有コード」方式です。

1. 誰か1人が「共有 → 同期」で合言葉を**自動作成**し、3人だけに伝えます（LINEなど）。
2. 変更した人が「共有コードを作る」を押し、出てきたコードをLINEに貼って送ります。
3. 受け取った人は合言葉を入れてコードを「取り込む」。両方の変更が合わさります（同じ項目は新しい方を採用し、削除も反映）。
4. 初めて参加する人は「この旅行に参加する」を押し、ホームで自分の名前を選びます。

- コードは合言葉から作った鍵（PBKDF2-SHA256 20万回）で **AES-GCM 256bit** 暗号化されています。合言葉を知らない人はコードを手に入れても中身を読めません。推測できるURLだけでデータが見える作りではありません。
- **リアルタイムでは同期されません**。変更を伝えたいときにコードを送り合う方式です。

## 起動方法（ローカル）

Node.js 22 以上が必要です。

```bash
cd drive-trip
npm install --legacy-peer-deps   # npm 10 の依存解決の不具合を避けるため
npm run dev                      # http://localhost:5173
npm test                         # テスト（計算・旅程・保存・マージ・暗号化）
npm run build                    # dist/index.html（1ファイル）を作成
```

スマートフォンから試すには `npm run dev -- --host` を実行し、同じWi-Fiのスマホで表示されたアドレスを開きます。

## 3人共有版を無料で公開する（Vercel + Neon）

らてのアプリと同じ Vercel（Hobby・無料）と Neon（Free・無料）を使います。カード登録は不要です。
共有URLを開いた3人が、アカウントなしで同じ内容を見て編集できます。

1. **Neon：旅行アプリ用のデータベースを作る**
   - https://console.neon.tech を開き、らてのアプリで使っているプロジェクトを選ぶ
   - 左メニュー「Databases」→「New database」→ 名前を `drivetrip` にして作成
     （らてのデータベースとは別にするため。らての中身には一切触れません）
   - 「Connect」で Database を `drivetrip` に切り替え、表示される接続文字列（`postgresql://…`）をコピー
2. **Vercel：プロジェクトを追加する**
   - https://vercel.com →「Add New…」→「Project」→ リポジトリ `777docomonejp/my-project` を「Import」
   - 「Root Directory」の「Edit」を押して `drive-trip` を選ぶ（ここが一番大事。らてのアプリとは別のプロジェクトになります）
   - Framework Preset が「Vite」になっていることを確認
   - 「Environment Variables」に `DATABASE_URL` を追加し、手順1の接続文字列を貼る
   - 「Deploy」を押す。数分で `https://<名前>.vercel.app` が発行されます
3. **使い始める**
   - 発行されたURLを開き、ホームの「共有URLを作る」を押す
   - 表示された「このURLを2人に送る」のURLをコピーして LINE で送る

### claude.ai 版から内容を引っ越す
1. claude.ai 版で「共有 → バックアップ → テキストでコピー」
2. Vercel 版で「共有URLを作る」を押す前に「共有 → バックアップ」の貼り付け欄に貼って「貼り付けから復元」
3. ホームで「共有URLを作る」

### しくみと無料枠
- 変更は1〜2秒で保存され、開いているほかの人の画面にも20秒ほどで反映されます。2人が同時に編集しても項目ごとに統合されるので、どちらかの変更が消えることはありません。
- 共有URLの `#k=` 以降が合言葉の役目をします（144bit のランダム値。推測できません）。データベースにはその値そのものではなくハッシュ値を保存します。
- 画面を見ていない間と、15分以上操作がない間はサーバーへの確認を止め、Neon の無料枠（計算時間）を使いすぎないようにしています。無料枠を超えても課金はされず、一時的に止まるだけです。Vercel・Neon とも有料プランへの切り替えはしないでください。
- ローカルで共有版を試す：`DRIVE_TRIP_SERVER=1 npm run dev`（データベースの代わりにメモリに保存します）

## ほかの無料公開先（共有は共有コード方式になります）

`npm run build` で作られる `dist/index.html` 1ファイルだけでも動きます。Netlify Drop（https://app.netlify.com/drop）にドラッグ＆ドロップするなど。GitHub Pages は非公開リポジトリだと有料プランが必要なので注意。

## 地図とデータについて

- 地図タイルは OpenStreetMap 公式タイルを利用します（APIキー不要）。タイル利用ポリシーに従い帰属表示を出し、ズーム範囲を絞っています。大量アクセスするアプリではありません。
- 地図画像が読めない環境（オフラインなど）では、県名とピンの位置関係だけを表示し、各観光地の「Googleマップで開く」「ここへナビ」が使えます。
- 同梱の観光地の**座標は概略位置**です（開発環境から地図サービスにアクセスできず、座標の照合ができなかったため「位置は概略」と表示しています）。ナビにはGoogleマップの名称検索を使うため、正確な場所に案内されます。
- 料金・営業日・冬季の運休や道路規制は変わります。アプリ内の料金は「参考」であり、公式サイトで確認してください。
- 初期の費用（往路520km・燃費15km/L・170円/L など）や旅程は**仮の値**です。「概算」として表示されるので、実際の値に直してください。

## データの保存とバックアップ

- **claude.ai のページで開いた場合：** 入力内容は自動でクラウド（そのページ専用の保存領域）にも保存されます。Safari・ホーム画面のアプリ・別の端末のどれで開いても、同じ内容が出ます。ホーム画面の「旅行の基本情報を編集」の下に保存状態が表示されます。
- **アップデートしても消えません。** 保存場所と形式は変えず、古い形式のデータもそのまま読み込みます（テストで確認）。
- 端末のデータとクラウドのデータは項目ごとに統合します。別々に入力された2つのデータがぶつかった場合は自動で捨てず、どちらを使うか画面で選びます。選ばなかった方も端末に退避し、「共有 → バックアップ → 退避したデータを戻す」で戻せます。
- 端末（localStorage）にも保存し、直前のデータを1世代自動バックアップします。保存データが壊れていたら自動で復元します。
- 念のため「共有 → バックアップ」でファイル保存またはテキストコピーも取ってください。
- Netlify などで公開した版にはクラウド保存がなく、端末保存と共有コードだけで動きます。

## 構成

Vite + React + TypeScript、地図は Leaflet。サーバー・データベースはありません。

- `src/lib/cost.ts`：費用計算と精算
- `src/lib/schedule.ts`：旅程の並べ替え・重複検知
- `src/lib/trip.ts`：初期データ、保存・読み込み、共有データのマージ
- `src/lib/share.ts`：共有コードの暗号化・復号
- `src/lib/remote.ts`：Vercel 版のサーバー同期
- `api/trip.ts`：保存API（Vercel Functions + Neon）
- `src/data/spots.json`：同梱の観光地データ
- `tests/`：単体テスト（41件）
